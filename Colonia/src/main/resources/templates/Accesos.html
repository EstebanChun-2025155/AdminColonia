Eliminación de accesos

Para eliminar un acceso haz clic en el botón rojo que se encuentra en el apartado de acciones.

02 TIP
Búsqueda rápida

Consulta registros

Para consultar un acceso específico, ingresa el ID en el buscador. Para mostrar todos los registros, presiona el botón Mostrar Todo.

03 TIP
Editar

Registros editables

Para editar un acceso, presiona el botón con ícono de lápiz. El sistema cargará los datos en el formulario de edición.
